# 🚀 Python Mobile Mini-Projects

Welcome to my Python practice repository! These are 3 beginner-friendly Python projects I built entirely on my mobile using Pydroid 3:

### 1. 🧮 Calculator
A simple interactive calculator that uses **Functions (`def`)** and **Conditionals (`if/elif/else`)** to perform basic mathematical operations.

### 2. 💸 Expense Tracker
A daily expense logger that uses **Dictionaries** to format data and **File Handling (`open`, `write`, `append`)** to permanently save expenses in a `.txt` file.

### 3. 🔐 Secure Password Generator
A tool that uses Python's inbuilt **`random` module** and **String concatenation** to generate highly secure, mixed-character passwords of any length.
